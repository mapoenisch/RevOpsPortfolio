# Lokaler Mecha-Referenznachbau

Quelle: https://mecha-xyz.webflow.io/

Start: `python3 -m http.server 4322 --bind 127.0.0.1`

Vorschau: http://127.0.0.1:4322/

HTML, CSS, Skripte, Bilder, Schriften, Videos, das 3D-Modell und die benötigten Three.js-Module sind lokal abgelegt. Die Herkunft steht in `asset-map.json` und `additional-assets.json`. Die Kontaktformulare sind für die lokale Referenz deaktiviert. Dieser Ordner dient dem visuellen Vergleich; Marcs zusammengeführtes Portfolio liegt separat in `../gtm-portfolio-mecha/`.
