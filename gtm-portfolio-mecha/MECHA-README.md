# Portfolio-Kopie im Mecha-Stil

Dieser Ordner ist die eigenständige Kopie von `../gtm-portfolio/`. Das Original bleibt unverändert.

Start: `npm run dev` · http://127.0.0.1:4321/

Build: `npm run build` · Ausgabe in `dist/`

Inhalte und bestehende Detailseiten stammen aus dem Portfolio. Die neue gemeinsame Gestaltung steht in `src/Mecha.tsx` und `src/mecha.css`. Die App-Anbindung steht in `src/App.tsx` und `src/main.tsx`.

Projektüberblick und Quellen: `../MECHA-UMSETZUNG.md`.

Das interaktive mp.-Logo besteht aus einem fein unterteilten schwarzen Oberflächengitter mit blauem Punkt: Vorder- und Rückseiten mit ausgespartem p-Innenraum, umlaufenden Tiefenlinien und gleichmäßig verteilten Querstreben. Es enthält keine gefüllten Flächen. Vorschau: `evidence/mp-surface-grid.png`. Mausreaktion und Produktions-Build sind geprüft.

Prüfung: `npm run check` und `npm run test:browser`.
