# Marc Pönisch – Bewerbungsportfolio

Bewerbungswebsite für Sales Operations und Revenue Operations mit drei Arbeitsproben, Projektchronik und Nachweisen.

Die Website liegt vollständig in [`gtm-portfolio/`](gtm-portfolio/README.md) (Vite, React, TypeScript). Dort stehen Start, Prüfung und Pflege der Inhalte.

## Weitere Ordner

- `Ursprung/` – Kursunterlagen (Task Sheets), Quelle für Inhalte der Projektchronik
- `docs/` – lose Notizen außerhalb der Website
